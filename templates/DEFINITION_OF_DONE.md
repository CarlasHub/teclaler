# Definition of Done

## Code feature

- Acceptance criteria met.
- Typecheck passes.
- Tests added/updated.
- Accessibility checked.
- Privacy/safety checked.
- Docs updated.
- No unrelated changes.

## Child-facing content

- Pedagogy reviewed.
- Pronunciation reviewed.
- Audio exists.
- Locale correct.
- No distracting visuals.
- No external links.

## Release

- Tests pass.
- Curriculum validates.
- Audio validates.
- Privacy/safety complete.
- Accessibility complete.
- Known issues documented.
- Rollback plan exists.
