# Release Governance

## Release levels

### Prototype

Internal only. Core learning loop works. Known issues allowed.

### Pilot

Small educator/parent group. Requires privacy notice, content review, QA, and feedback channel.

### Public web/PWA

Requires legal/privacy review, security review, support contact, and release checklist.

### Android/iOS

Requires platform-specific app privacy declarations, screenshots, icons, child-safety review, and device testing.

## Release checklist

- App version assigned.
- Curriculum pack version assigned.
- Audio version assigned.
- Changelog updated.
- Tests passing.
- Curriculum validator passing.
- Audio validator passing.
- Accessibility review complete.
- Privacy/safety review complete.
- No tracking/ads.
- No external links in child mode.
- Known issues documented.
- Rollback plan exists.

## Rollback triggers

- Incorrect pronunciation in released word.
- Broken word completion audio.
- Child data exposure.
- Tracking SDK accidentally included.
- External link in child mode.
- Offline PWA failure for core lesson.
