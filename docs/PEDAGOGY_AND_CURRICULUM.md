# Pedagogy and Curriculum Governance

## Pedagogical model

TeclaLer teaches Portuguese reading through a progression:

```text
letters → syllables → words → sentences
```

Typing is not the goal by itself. Typing is the action that reinforces reading.

## Portuguese sequence

### Stage 1: vowels

```text
a e i o u
```

### Stage 2: simple CV syllables

```text
ma me mi mo mu
pa pe pi po pu
la le li lo lu
sa se si so su
ca co cu
```

### Stage 3: short words

```text
casa mala pato sapo bola lua mesa lata pipa mimo
```

### Stage 4: accents/nasal sounds

```text
mãe pão não avó avô café
```

### Stage 5: digraphs

```text
chave filho galinha carro massa
```

## Curriculum item review

Each item must be reviewed for:

- spelling,
- syllable segmentation,
- grapheme sequence,
- audio IDs,
- Portuguese variant,
- age appropriateness,
- image appropriateness.

## Feedback rules

Good wrong-key feedback:

```text
Esta é a letra M. Precisamos da letra C.
```

Bad feedback:

```text
Wrong!
```

Worse feedback:

```text
A siren, red flashing, and a mascot losing the will to live.
```

## AI content rule

AI can help draft content, but child-facing curriculum must be human-reviewed before release.
